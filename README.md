# mcp-mail 🐝

Repository di progettazione del server MCP e degli sciami di agenti.

**Architetto:** Alessandro. **Assistente di coordinamento:** Lia.

## Organizzazione Git

- `main` — regole condivise, documentazione di riferimento e integrazioni approvate.
- `Alessandro` — ramo di progettazione riservato all'architetto.
- `Lia` — ramo per proposte, coordinamento e sviluppo assistito.
- Futuri rami dedicati — uno per ciascun agente, quando decisi dall'architetto.

Le regole ufficiali si trovano in [`REGOLE.md`](REGOLE.md).

**Nota tecnica:** un ramo Git isola versioni di codice e documenti; non avvia autonomamente un agente. L'esecuzione e il coordinamento degli sciami richiederanno componenti runtime da progettare e implementare.
